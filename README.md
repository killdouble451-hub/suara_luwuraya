# 🌊 Proyek Narasi Publik: Perjuangan Provinsi Luwu Raya 2029

Selamat datang di repositori resmi **Anomali Pisces**. Repositori ini berisi narasi perjuangan, kritik politik, dan gagasan radikal mengenai masa depan Sulawesi Selatan dan pembentukan **Provinsi Luwu Raya**.

## 📌 Tentang Proyek Ini
Proyek ini diawali sebagai sebuah artikel publik tunggal yang menyuarakan aspirasi masyarakat Wija To Luwu yang terhambat oleh kebijakan elite saat ini. Tujuan utamanya adalah:
1. **Penyadaran Publik:** Mengedukasi masyarakat mengenai hambatan pemekaran wilayah Luwu Raya.
2. **Gagasan Politik:** Mendorong pasangan calon Gubernur-Wagub Sulsel 2029, **Fatmawati Rusdi Masse - Irwan Bachri Syam**, sebagai solusi konkret perjuangan.
3. **Arsip Perlawanan:** Menjadi wadah digital bagi pemikiran-pemikiran kritis dari Anomali Pisces.

## ✍️ Penulis: Anomali Pisces
Narasi ini disusun oleh **Anomali Pisces**, seorang penggerak gagasan yang fokus pada isu keadilan wilayah, pemberdayaan masyarakat sipil, dan transformasi politik di Sulawesi Selatan.

## 🚀 Fitur Website (Versi Saat Ini)
- **Artikel Responsif:** Nyaman dibaca di perangkat seluler maupun desktop.
- **Simulasi Interaksi:** Fitur Like dan Komentar sebagai wadah awal partisipasi pembaca.
- **Visual Bersih:** Desain yang fokus pada teks agar pesan tersampaikan secara tajam.

## 🛠️ Rencana Pengembangan (Roadmap)
Website ini dirancang untuk berevolusi dari sekadar file statis menjadi platform dinamis:
- [ ] **Migrasi ke CMS:** Agar penulis dapat memposting artikel baru langsung dari browser tanpa menyentuh kode.
- [ ] **Database Komentar Real-time:** Menggunakan Firebase/Supabase agar diskusi publik tersimpan secara permanen.
- [ ] **Sistem Login Admin:** Akses khusus bagi penulis (Anomali Pisces) untuk mengelola konten.
- [ ] **Fitur Share:** Integrasi media sosial untuk penyebaran gagasan yang lebih luas.

## 📂 Cara Menjalankan Secara Lokal
1. Unduh file `index.html`.
2. Buka file tersebut menggunakan browser pilihan Anda (Chrome, Firefox, Safari).
3. Untuk mempublikasikan, unggah file ini ke **GitHub Pages**.
